# Trailer Park Productions — Android app

A small Android app that opens https://trailerparkproductions.net full screen with bottom tabs (Home, Stories, Media, Podcast, Store), pull-to-refresh, and the TPP logo as its icon. The website's own top menu is hidden inside the app, so the tabs are the only navigation. Outside links (sponsors, socials) open in the browser.

Built automatically by GitHub Actions on every push — see the Actions tab for the latest APK (artifact "TrailerParkProductions-apk").

The app shows the live site, so site updates appear in the app automatically. Rebuild only if the app itself changes.
